# 🛒 CartSense

> India's AI-Powered Shopping Assistant

CartSense is an AI-driven shopping platform that helps users decide:

- 🛍️ Where to Buy
- ⏰ When to Buy
- 🤖 Whether to Buy

Unlike traditional price comparison websites, CartSense combines real-time pricing, coupons, AI insights, and price history to help users make smarter purchasing decisions.

# ⚙️ Installation

```bash
git clone https://github.com/Emineffex/cartsense-smart-shopping.git

cd cartsense-smart-shopping

npm install

npm run dev
```
